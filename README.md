# nrf24_blink
Remote Blink, with Autoack or custom message

Solid and simple. It has a process table structure that you can use for more complex tasks later on.
Between 500us and 1ms for a roundtrip. This can be optimized further when you know the goal or what program you gonna write.
It is done on a Rp Pico 2040 but other chips work too, just change the spi-pins
